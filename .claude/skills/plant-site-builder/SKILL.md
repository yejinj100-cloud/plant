# Plant Site Builder — 페이지 구조 가이드

식물 도감 데이터를 실제 화면으로 옮길 때 지켜야 할 구조와 데이터 연결 규칙. 시각적 스타일 자체는 `frontend-design`·`artifact-design` 스킬을 따르고, 이 스킬은 "식물 도감"이라는 도메인에 필요한 화면 구조만 다룬다.

## 페이지 구성

1. **히어로/이번 달 추천 식물** — `monthly_pick`에 오늘 날짜의 월이 포함된 식물을 상단에 강조 노출한다. 후보가 여러 개면 그중 대표 1종을 고르고 나머지는 목록에서 뱃지로 표시한다.
2. **분류 필터** — `categories` 배열로 필터 탭/칩을 만든다. 하드코딩 금지: 데이터가 바뀌면 필터도 자동으로 바뀌어야 한다.
3. **식물 목록(카드형)** — 카드마다 최소 이름(국문+학명), 카테고리, 물주기 요약을 보여준다.
4. **식물 상세** — 카드 클릭 시 분류(과/속), 물주기, 개화 시기, 관리 팁 전체를 보여준다. 모달이든 별도 섹션이든 방식은 자유이나, 5개 핵심 필드가 모두 노출되어야 한다.

## 데이터 연결 규칙
- 이 스킬이 아니라 `_workspace/01_content/plants.json`이 유일한 데이터 소스다. 화면에 임의의 식물이나 정보를 지어내지 않는다.
- 카드/상세뷰를 연결할 때 `id` 필드로 참조한다 — 다른 값(이름 등)으로 연결하면 이름이 같은 식물이 생겼을 때 깨진다.
- 카테고리 필터의 "전체" 같은 옵션을 추가하는 것은 괜찮지만, 데이터에 없는 카테고리를 필터에 넣지 않는다.

## 소재에서 나온 디자인 선택
식물 도감은 유기적 소재다. `frontend-design` 스킬의 원칙대로, "일단 깔끔한 SaaS 대시보드" 같은 기본값을 피하고 다음과 같은 선택지를 검토한다:
- 잎/화분 모양을 모티프로 한 카드 프레임이나 구분선
- 계절/월별 색감 변화(이번 달 추천 섹션에 반영)
- 카테고리별 아이콘이나 일러스트(관엽/다육/허브/개화식물을 시각적으로 구분)

## 퍼블리시
Artifact 도구로 퍼블리시하고, 결과 URL을 `_workspace/02_site/artifact_url.txt`에 저장한다. 이미 URL이 있으면(재실행) 같은 `url`로 업데이트 퍼블리시한다 — 새 아티팩트를 만들지 않는다.
